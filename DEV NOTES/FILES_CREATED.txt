================================================================================
                           AUTOMATION SCHEDULE
================================================================================

GitHub Actions runs 3x daily:
  07:00 WIB (00:00 UTC)  → Morning update
  15:00 WIB (08:00 UTC)  → Afternoon update
  23:00 WIB (16:00 UTC)  → Evening update

Each run:
  1. Extracts CSRF token
  2. Scrapes SELL prices
  3. Scrapes BUY prices
  4. Deduplicates & sorts
  5. Saves to data/ folders
  6. Updates root JSON files
  7. Auto-commits to Git
  8. Time: ~1-2 minutes per run
